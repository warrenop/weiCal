欢迎使用 微记账本

导入你的第一份微信账单，开启本地加密、可视化记账

  1. 1
    在微信里申请账单：我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单，按月申请
  2. 2
    邮件收到 zip，解压得到 .csv 或 .xlsx 文件
  3. 3
    点下方按钮上传，分类与图表会自动生成

数据存在本地 ~/Library/Application Support/mycal/，AES-256 加密，仅你可见。
